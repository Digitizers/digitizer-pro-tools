What's inside

Each module does one job and replaces a plugin or a snippet you used to carry. Turn on only what the site needs.

Setup and maintenance

New sites start ready. Running sites stay quiet.

  • OnboardingInstalls Digitizer's baseline on a new site without touching what is already there.
  • Update PolicyHolds a major WordPress release until your plugins catch up. Security releases always go through.
  • Update EmailsSilences the "your site was updated" emails. Failure emails still arrive.
  • Agent LogA log of everything automations changed on the site: who, what and when.
  • Site TweaksSecurity headers, SVG uploads with unsafe code stripped, and less dead weight on Elementor sites.

Privacy and access

Who sees what, and when.

  • Cookie BannerA multilingual consent banner that holds tagged scripts until consent, supports Google Consent Mode v2, and clears cookies on refusal.
  • Content ControlRestrict content by role, set site-wide rules, or put the whole site behind a login.
  • Hide LoginMoves the login page to an address of your choice.
  • User Role EditorEdit what each role is allowed to do.
  • Disable CommentsTurns comments off, comment feeds included, without touching WooCommerce reviews.
  • Shabbat KeeperCloses the site, or just the shop and forms, from candle lighting to Havdalah and on Jewish holidays.

Content and editing

Fewer heavy widgets, less pasted code.

  • Duplicate PostOne-click copies, Elementor content included.
  • EmbedPDFs and Google Docs in a responsive frame.
  • Code HighlighterSyntax highlighting with no external CDN.
  • Copy URLA "copy this page's address" field in one shortcode.
  • Related Posts FillFills Elementor's related posts widget when the category runs short.
  • Rank Math BreadcrumbsAdds your Blog and Shop pages to Rank Math breadcrumbs.

Marketing and performance

The campaign survives all the way to the form.

  • UTM PassthroughCarries UTM parameters through internal links as the visitor browses, HubSpot ad parameters included.
  • Cache Ignore ParamsLets WP Rocket serve cached pages to visits that arrive with tracking parameters.

WooCommerce

A cleaner checkout.

  • WooCommerce CheckoutSuggests fixes for mistyped email addresses and validates Israeli phone numbers.
  • Checkout Field EditorAdd, hide and reorder checkout fields.
  • Name Your PricePay-what-you-want pricing, with a minimum and maximum enforced on the server.

Integrations

Your site talks to your automations.

  • REST BridgeJetEngine and Rank Math fields in the REST API, and Elementor content edits that keep the design intact. More on WordPress API work
  • Resend MailSends all site email through Resend, with a delivery log.

Why one plugin

Fewer plugins means fewer updates to track, fewer conflicts, and less code someone pasted in once and forgot.

Off by default

Activating it changes nothing. Each module turns on only when you decide, so the site runs exactly what you chose.

Built for multilingual sites

Full right-to-left support on every screen, a Hebrew interface, and a cookie banner that follows the page's language and direction.

Works with your cache

The banner, the restrictions and the parameters keep working behind WP Rocket, Cloudflare and optimization plugins.

No data sent home

The plugin collects and sends no usage data. The update check asks GitHub without sending your site's address. A module built around an outside service, like Resend, talks to that service only.

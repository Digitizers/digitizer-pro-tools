מה יש בפנים

כל מודול עושה דבר אחד, ומחליף תוסף או סניפט שהיה באתר. מדליקים רק את מה שהאתר צריך.

הקמה ותחזוקה

אתר חדש מוכן, ואתר קיים שקט.

  • Onboardingמתקין את הבסיס של Digitizer באתר חדש, בלי לגעת במה שכבר קיים.
  • Update Policyמעכב גרסה ראשית של וורדפרס עד שהתוספים מתעדכנים. עדכוני אבטחה עוברים תמיד.
  • Update Emailsמשתיק את מיילי "האתר עודכן". מייל על כישלון יוצא תמיד.
  • Agent Logיומן של כל מה שאוטומציות שינו באתר: מי, מה ומתי.
  • Site Tweaksכותרות אבטחה, העלאת SVG עם ניקוי של קוד מסוכן, והסרת משקל מיותר מאתר Elementor.

פרטיות וגישה

מי רואה מה, ובאיזה תנאים.

  • Cookie Bannerבאנר הסכמה רב-לשוני, חסימת סקריפטים עד הסכמה, Google Consent Mode v2, ומחיקת עוגיות בסירוב.
  • Content Controlהגבלת תוכן לפי תפקיד, כללים גלובליים ונעילת האתר כולו מאחורי התחברות.
  • Hide Loginמעביר את דף ההתחברות לכתובת אחרת.
  • User Role Editorעריכת ההרשאות של כל תפקיד.
  • Disable Commentsמכבה תגובות, כולל פידי התגובות, בלי לפגוע בביקורות WooCommerce.
  • Shabbat Keeperסוגר את האתר, או רק את החנות והטפסים, מכניסת שבת עד צאתה ובחגים.

תוכן ועריכה

פחות ווידג׳טים מורכבים, פחות קוד מודבק.

  • Duplicate Postשכפול בלחיצה, כולל תוכן Elementor.
  • Embedהטמעת PDF ומסמכי Google בתוך מסגרת רספונסיבית.
  • Code Highlighterהדגשת קוד בלי CDN חיצוני.
  • Copy URLשדה "העתקת כתובת העמוד" בשורטקוד אחד.
  • Related Posts Fillממלא את ווידג׳ט "פוסטים קשורים" של Elementor כשאין מספיק פוסטים מאותה קטגוריה.
  • Rank Math Breadcrumbsמוסיף את "בלוג" ו"חנות" לפירורי הלחם של Rank Math.

שיווק וביצועים

הקמפיין נשמר עד הטופס.

  • UTM Passthroughפרמטרי UTM עוברים עם הגולש לקישורים הפנימיים, כולל פרמטרי המודעות של HubSpot.
  • Cache Ignore ParamsWP Rocket מגיש מה-cache גם ביקורים עם פרמטרי מעקב.

WooCommerce

קופה מדויקת יותר.

  • WooCommerce Checkoutתיקון כתובות מייל עם שגיאת הקלדה ובדיקת מספרי טלפון ישראליים.
  • Checkout Field Editorהוספה, הסתרה וסידור של שדות בקופה.
  • Name Your Price"שלם כמה שתרצה", עם מינימום ומקסימום שנאכפים בשרת.

אינטגרציות

האתר מדבר עם האוטומציות שלכם.

  • REST Bridgeשדות JetEngine ו-Rank Math ב-REST API, ועריכת תוכן Elementor בלי לשבור את העיצוב. עוד על חיבור API לוורדפרס
  • Resend Mailכל המיילים של האתר דרך Resend, עם יומן שליחה.

למה תוסף אחד

פחות תוספים זה פחות עדכונים לעקוב אחריהם, פחות התנגשויות ופחות קוד שמישהו הדביק פעם ושכח.

כבוי כברירת מחדל

ההפעלה לא משנה כלום באתר. כל מודול נדלק רק כשמחליטים, והאתר מריץ בדיוק את מה שבחרתם.

נבנה לאתרים בעברית

ממשק מלא בעברית, RTL בכל מסך, ובאנר עוגיות שעובר שפה וכיוון לפי העמוד.

עובד עם ה-cache

הבאנר, ההגבלות והפרמטרים עובדים גם מאחורי WP Rocket, Cloudflare ותוספי אופטימיזציה.

בלי שליחת מידע החוצה

התוסף לא אוסף ולא שולח נתוני שימוש. בדיקת העדכונים פונה ל-GitHub בלי כתובת האתר. מודול שתפקידו שירות חיצוני, כמו Resend, עושה רק את זה.
